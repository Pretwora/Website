# 🏹 ArrowShot — Клуб стрельбы из лука в Санкт-Петербурге

Современный лендинг для клуба стрельбы из лука **ArrowShot** — место, где каждый может почувствовать силу точного выстрела, медитацию концентрации и адреналин спорта.

---

## 📋 О проекте

ArrowShot — это реальный бизнес клуба стрельбы из лука в Санкт-Петербурге. Сайт разработан для:
- **Привлечения новых клиентов** через эстетику и атмосферу спорта
- **Записи на занятия** и пробные уроки
- **Продажи спортивного инвентаря** и оборудования
- **Демонстрации профессионализма** и опыта тренеров

## 💻 Технический стек

### Фронтенд
- **HTML5** — семантичная разметка
- **CSS3** — адаптивный дизайн, flexbox, grid
- **Vanilla JavaScript** — чистый код без фреймворков

### Библиотеки и инструменты
- **Three.js** — 3D анимации (частицы, стрела, интерактивный лук)
- **GSAP (GreenSock)** — плавные анимации скролла
- **ScrollTrigger** — триггеры анимаций при скролле
- **Google Fonts** — современные шрифты

### Принципы разработки
- **Чистый и быстрый код** — без фреймворков, максимальная производительность
- **Mobile-first** — полная адаптивность для всех экранов
- **Progressive Enhancement** — базовая функциональность работает везде

## 🚀 Как использовать

### Локальная разработка
```bash
# Клонировать репозиторий
git clone https://github.com/Pretwora/Website.git
cd Website

# Открыть в браузере (используя простой HTTP сервер)
```
